# DeModel

用来查看各种模型文件的格式和字节。打开后左侧是结构树，右侧是十六进制；点左侧字段会定位到它在文件中的字节。

## 当前支持格式

- [x] safetensors

safetensors：前 8 字节是小端 u64，值是 JSON 头长度；接着是 JSON；其余是张量字节。`data_offsets` 相对数据区，范围是 `[起始, 结束)`。`__metadata__` 只在头里，不是张量。JSON 头整段解析，上限 512MB。

## 主要功能

- **文件**：打开、拖入、最近 10 个。未打开时不显示路径。
- **结构树**：整栏一棵树。顶部按键和值搜索，命中项保留祖先并展开。单击字段，右侧选中该字段自己的字节。
- **单位格式**：地址和树里的整数可在十六进制、十进制之间切换，默认十六进制。浮点保持十进制。
- **字段说明**：勾选后，字段旁显示该格式下的字段含义。
- **偏移跳转**：解析时按格式规则标出指向文件字节的字段。safetensors 中，带 dtype、shape、`data_offsets` 的对象，其偏移数字可右键跳转，目标是 `数据区起点 + 相对偏移`。
- **十六进制**：按行虚拟滚动。可按十六进制字节或 UTF-8 文本搜索。选中区域右键可定位回左侧字段。
- **底部**：当前偏移、区域名和选区长度。从光标起按所选单位（u8 到 f64）小端解码最多 16 个值。这里的 10/16 只影响这行整数。

## 架构

TypeScript，CommonJS。`tsc` 输出到 `dist/`，页面和样式从 `src` 复制过去。渲染进程是普通脚本，不打包。

```
渲染进程  renderer.ts + index.html
    │  window.api（contextBridge）
预加载    preload.ts
    │  IPC
主进程    main.ts ── parse.ts
    │
文件句柄  会话内只保留一个打开的文件
```

- **main.ts**：窗口、对话框、最近文件（`userData/recent.json`）。打开时调用解析并握住文件句柄。`read` 按偏移读取，单次最多 1MB。开发时监视 `dist`，页面变化则重载，主进程变化则重启。
- **preload.ts**：在隔离上下文里只暴露打开、按路径打开、读取、最近文件、编辑命令和退出。渲染进程没有 Node。
- **parse.ts**：按格式解析。每种格式产出同一份 `FileInfo`：结构树节点带文件偏移，需要跳转的字段带 `base`、`offset`、`target`。当前只实现 safetensors。
- **renderer.ts**：树和十六进制都只画可见行。滚动条用比例映射到行号。读取有 256KB 缓存。菜单在窗口内绘制。展示不绑定某一种格式，格式差异由解析结果带进来。

主进程负责文件和按格式解析，渲染进程只拿 `FileInfo` 和按需读到的字节。
